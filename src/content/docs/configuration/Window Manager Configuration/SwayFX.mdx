## What is SwayFX?

SwayFX is a fork of the Sway window manager that focuses on adding eye-candy effects. It currently has support for rounded corners, borders, titlebars, blur, shadows and animations.

StratOS Linux offers a basic SwayFX spin as an option to users trying to venture into the world of Window Managers. The config provided by default is very basic. Users can feel free to customise their SwayFX configs as they see fit by using it as a starting point.

## Keybindings

These are the default keybindings included in the StratOS SwayFX spin. You can take a look at them and change them according to your requirements from the configuration files if you wish to do so.

### Application Control
import { Kbd } from 'starlight-kbd/components';

|Description| Keybinding|
|-----------|-----------|
| Open Zen Browser | <Kbd linux="Super+B" />|
| Open Application Launcher (Vicinae) | <Kbd linux="Super+R"/>|
| Open File Manager (Thunar) | <Kbd linux="Super+E"/>|
| Open Terminal (Ghostty) | <Kbd linux="Super+T"/>| 
| Toggle Conky Widget| <Kbd linux="Super+C"/>|

### Window Management

|Description|Keybinding|
|-----------|----------|
|Switch Workspaces|<Kbd linux="Super+[0-9]"/>|
|Move active window between workspaces|<Kbd linux="Super+Shift+[0-9]"/>|
|Move active window silently between workspaces|<Kbd linux="Super+Alt+[0-9]"/>|

|Description|Keybinding|
|----------|------------|
